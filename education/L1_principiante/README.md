## Filosofia di L1

- Spiegare **una cosa alla volta**, senza saltare passaggi
- Mai usare gergo senza spiegarlo
- Esempi concreti con asset reali (BTC, ETH) dove possibile
- Onestà sui rischi: chi promette guadagni facili sta mentendo
